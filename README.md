# ☕ Example

## Two Sum

### Problem

Given an integer array `nums` and an integer `target`, return the indices of the two numbers such that they add up to the target.

### Example

```text
Input:
nums = [2, 7, 11, 15]
target = 9

Output:
[0, 1]
```

### Pattern

```text
HashMap
```

### Key Idea

Instead of checking every pair using two loops, store previously seen numbers in a HashMap and look for the required complement.

```text
complement = target - currentNumber
```

### Complexity

```text
Time  → O(n)
Space → O(n)
```
